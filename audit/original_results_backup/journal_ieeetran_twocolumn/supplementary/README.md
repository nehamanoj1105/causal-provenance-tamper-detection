# Supplementary Material

This directory is reserved for journal supplementary content. The extended
material currently lives in the main journal manuscript and in the audit package:

| Supplementary item | Location |
|---|---|
| Per-seed raw results | `audit/FINAL_RESULTS/raw_results/` |
| Full metric tables | `audit/FINAL_RESULTS/tables/` |
| Statistical tests | `audit/FINAL_RESULTS/statistics/` |
| Scalability detail | `audit/FINAL_RESULTS/scalability/` |
| Corrected audit reports | `audit/final_audit_report.md` + companions |
| Verification scripts | `audit/scripts/`, `audit/manuscript_validation/` |

No supplementary file is placeheld with fabricated content; when a supplementary
document is written it should draw only on the verified artifacts above.
